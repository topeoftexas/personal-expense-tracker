# SpendWise v1.0
## Personal Expense Tracker

SpendWise is a responsive personal finance web application
built using HTML, CSS, and JavaScript.

## Features

- Financial dashboard
- Income and expense tracking
- Add, edit, and delete transactions
- Spending categories
- Monthly budget management
- Six-month financial charts
- Search and filter transactions
- Export transactions to CSV
- Backup and restore financial data
- Dark mode
- Responsive interface
- Local browser storage

## Technologies

Frontend: HTML5, CSS3, JavaScript
Storage: Browser LocalStorage
Architecture: Client-side web application

## Installation

1. Download and extract the project.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start recording your transactions.

Alternatively, use Visual Studio Code with Live Server.

## Privacy and Storage

Financial data is stored locally in the browser.
No cloud synchronization or user authentication is included.

Export a backup regularly to avoid losing your data.
Clearing browser storage may delete saved transactions.
